One funny line for the [Make the Judge Laugh in One Line](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21) bounty on make.fun — a blind-judged contest where a judge model reads the lines two at a time and picks the funnier one. The entry turns the request back on its maker: an AI assistant told to act more human answers with the two most human behaviours it could copy.

> I asked my AI assistant to act more human, so now it ignores my messages and bills me for emotional support.

## Run it

```sh
node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), enforcing the gate first: a single non-blank line of 1–200 characters, no leading or trailing whitespace, ASCII-only so the character count holds in UTF-8 bytes too, then reads the file back to prove the gate will see exactly the line above.
